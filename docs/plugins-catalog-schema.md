# Специфікація схеми каталогу плагінів MZGram (catalog/index.json)

## 1. Загальний огляд
Каталог плагінів MZGram дозволяє користувачеві підключати офіційні або власні сховища плагінів через raw URL репозиторію. Додаток не має жорстко зашитих сторонніх серверів: за замовчуванням каталог вимкнено («Каталог не підключено»), і з'єднання відбувається лише за явною дією користувача.

Файл маніфесту каталогу має назву `index.json` та розташовується у корені вказаного URL сховища.

---

## 2. Модель безпеки та приватності
1. **Явне підключення**: URL вказується користувачем вручну в розділі «Каталог плагінів» (або використовується встановлений за замовчуванням URL репозиторію власника). Мережа не робить жодних запитів до каталогу до явного відкриття користувачем розділу каталогу.
2. **Обов'язкова перевірка SHA-256**: Кожен завантажений `.plugin`-файл проходить обов'язкову перевірку контрольної суми SHA-256 із зазначеною в `index.json`. У разі відсутності хешу або його невідповідності файл негайно видаляється з пристрою, а встановлення скасовується з помилкою безпеки.
3. **Екран дозволів (Consent Sheet)**: Перед остаточним збереженням плагіна відкривається стандартний екран дозволів (як для локальних файлів із №51), де всі запитані дозволи за замовчуванням зняті.
4. **Статичний аналіз коду (Capability Scan)**: Перед запуском виконується перевірка AST коду на наявність недекларованих викликів, обфускації чи заборонених операцій (№67).
5. **Авторство та приватність**: У всіх екранах каталогу MZGram автор кожного запису завжди відображається як MZGram, а іконка використовується стандартна власна. Будь-які поля автора або зовнішнього аватара в `index.json` є необов'язковими та повністю ігноруються клієнтом; клієнт не виконує жодних запитів до сторонніх адрес заради завантаження картинок.

---

## 3. Схема файлу index.json

### Кореневі поля
| Поле | Тип | Обов'язкове | Опис |
| :--- | :--- | :---: | :--- |
| `name` | string | Так | Назва каталогу/репозиторію плагінів. |
| `description` | string | Ні | Короткий опис збірки або репозиторію. |
| `plugins` | array | Так | Список доступних плагінів каталогу (може бути порожнім `[]`). |

### Поля об'єкта плагіна в `plugins`
| Поле | Тип | Обов'язкове | Опис |
| :--- | :--- | :---: | :--- |
| `id` | string | Так | Унікальний ідентифікатор плагіна (має збігатися з `__id__`). |
| `name` | string | Так | Відображуване ім'я плагіна. |
| `name_i18n` | object | Ні | Словник локалізованих назв (код мови -> назва) для описових найменувань. |
| `version` | string | Так | Версія плагіна (наприклад, `"1.0.0"`). |
| `description` | string | Так | Базовий опис функціональності плагіна англійською мовою. |
| `description_i18n` | object | Ні | Словник локалізованих описів (код мови -> текст). Порядок вибору: поточна мова, en, description. |
| `file` | string | Так | Відносний шлях або ім'я файлу (наприклад, `"plugins/calc/1.0.0/calc.plugin"`). |
| `url` | string | Ні | Прямий URL для завантаження (якщо файл хоститься окремо від каталогу). |
| `sha256` | string | Так | 64-символьний шістнадцятковий хеш SHA-256 файлу в нижньому регістрі. |
| `size` | integer | Ні | Розмір файлу плагіна в байтах. |
| `min_app_version` | string | Ні | Мінімальна сумісна версія MZGram (наприклад, `"1.0.0"`). |
| `requirements` | array[string] | Ні | Список Python-залежностей із PyPI (для mini-pip). |
| `permissions` | array[string] | Ні | Запитувані дозволи (`messages.read`, `messages.send`, `ui`, `files`, `network`, `hooks`). |
| `author` | string | Ні | Застаріле / ігнорується клієнтом. Автор у каталозі завжди "MZGram". |
| `avatar` / `icon_url` | string | Ні | Застаріле / ігнорується клієнтом. Сторонні картинки не завантажуються. |
