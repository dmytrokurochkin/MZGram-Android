# Сторонні мережеві з'єднання MZGram Android (Third-Party Connections)

> **Документ фази C2 (§3.5)**: Повний технічний опис усіх вихідних мережевих з'єднань клієнта MZGram Android з будь-якими сторонніми серверами (поза інфраструктурою Telegram).
>
> **Принцип прозорості та контролю (§3.5 Rule 2)**: Жоден сторонній мережевий запит не здійснюється без явної згоди або налаштування користувача. Усі нові та оновлені запити проходять через єдиний шлюз `MZGramNetGate`, який перевіряє активність відповідної функції, блокує несанкціонований трафік та логує виклики в системний журнал `logcat` із тегом `MZGramNet` (без передачі секретів або вмісту повідомлень).

## 2. Спеціальні списки аудиту безпеки

### 2.1. Відбувається без прямої дії користувача (фонові запити, таймери, старт)

1. **Перевірка оновлень MZGram (`api.github.com`)**:
   - Періодичний запит кожні кілька годин для виявлення нових стабільних релізів.
   - Може бути повністю вимкнено у: *Налаштування > MZGram > Інше > Оновлення*.
2. **Курси валют у Pill Stack (`api.coinbase.com`, `api.gold-api.com`)**:
   - Опитування кожні 15 хвилин, **тільки якщо** користувач увімкнув відповідний віджет у пошуковому рядку.
   - За замовчуванням вимкнено.
3. **Шлюз UnifiedPush (`p2p.belloworld.it`)**:
   - Фонова підтримка каналу доставки сповіщень, **тільки якщо** обрано дистриб'ютор UnifiedPush.
   - За замовчуванням вимкнено (використовується стандартний механізм Telegram).
4. **DNS-over-HTTPS запити (`cloudflare-dns.com`, `dns.google`, `dns.adguard-dns.com`, Custom DoH)**:
   - Відбуваються під час резолвінгу адрес дата-центрів та зовнішніх API, **тільки якщо** DoH увімкнено користувачем у *Загальні > Мережа та завантаження*.
   - За замовчуванням вимкнено.

### 2.2. Відправляє вміст повідомлень або вкладень

1. **Рушії перекладу (Google Translate, DeepL, Mozhi)**:
   - Відправляють лише виділений користувачем фрагмент тексту або текст обраного повідомлення.
   - Запуск виключно за явною дією: натискання кнопки «Перекласти», смужки перекладу або опції контекстного меню.
2. **ШІ-сервіси перекладу та аналізу (OpenAI, Anthropic, Gemini, DeepSeek)**:
   - Відправляють текст повідомлення та системний промпт через офіційні API користувача.
   - Повністю вимкнено за замовчуванням, потребує особистого API-ключа.
3. **Вікно «Запитати ШІ» (WebView)**:
   - Вставляє виділений текст повідомлення та обрані користувачем файли (до 10 шт, до 30 МБ) у веб-інтерфейс обраного сервісу.
   - Жодні дані не передаються автоматично без натискання користувачем кнопки відправки на самому сайті.

## 3. Детальний опис кожного з'єднання (11 обов'язкових пунктів)

### 3.1. Google Translate (безкоштовний рушій перекладу)
1. **Функція**: Переклад повідомлень та чатів за допомогою безкоштовного мобільного ендпоінту Google Translate. Вмикається: *Налаштування > MZGram > Загальні > Переклад повідомлень*. Типово увімкнено (`chatTranslationBar = true`).
2. **Сервер**: `https://translate.googleapis.com/translate_a/single`, протокол HTTPS (порт 443).
3. **Коли**: Лише при явному натисканні користувачем кнопки «Перекласти» над повідомленням або увімкненому автоперекладі чату.
4. **Що відправляється**: Текст перекладу, мова джерела (`sl=auto`), цільова мова (`tl=...`), клієнтський ідентифікатор `client=gtx`. Жодних персональних даних або ID акаунта.
   *Приклад:* `GET /translate_a/single?client=gtx&sl=auto&tl=uk&dt=t&q=Hello%20world`
5. **Що приходить**: JSON-масив із перекладеними фразами. Відображається у виринаючому вікні або замінює текст на екрані. Не зберігається у базі даних.
6. **Що бачить сервер**: IP-адресу клієнта, рядок User-Agent, текст для перекладу. Прив'язка до Telegram-акаунта неможлива.
7. **Ключі й акаунти**: Ключі не потрібні; акаунт Google не використовується.
8. **Вимкнення**: *Налаштування > MZGram > Загальні > Показувати кнопку «Перекласти»* (Вимк.). Тест: `MZGramNetGate.isFeatureEnabled(FEATURE_TRANSLATION)` повертає `false`, запит блокується.
9. **Код**: `MZGramTranslator.translateGoogle`, бібліотека `HttpURLConnection` через `MZGramNetGate.openConnection`.
10. **Походження**: Власна реалізація MZGram.
11. **Ризики**: Сервер Google бачить текст повідомлень, що надсилаються на переклад.

---

### 3.2. DeepL Translation API
1. **Функція**: Високоякісний машинний переклад через DeepL API. Вмикається: *Налаштування > MZGram > Загальні > Постачальник перекладу: DeepL*. Типово вимкнено.
2. **Сервер**: `https://api.deepl.com/v2/translate` (Pro) або `https://api-free.deepl.com/v2/translate` (Free), HTTPS (порт 443).
3. **Коли**: При натисканні перекладу, якщо обрано постачальника DeepL.
4. **Що відправляється**: Заголовок авторизації `Authorization: DeepL-Auth-Key <key>`, тіло JSON з текстом `text` та цільовою мовою `target_lang`.
5. **Що приходить**: JSON-відповідь із перекладеним текстом.
6. **Що бачить сервер**: IP-адресу, API-ключ користувача, переданий текст.
7. **Ключі й акаунти**: Особистий ключ DeepL користувача. Зберігається у локальному сховищі `SharedPreferences` на пристрої.
8. **Вимкнення**: Зміна постачальника на Telegram або Google.
9. **Код**: `MZGramTranslator.translateDeepL`, `HttpURLConnection` через `MZGramNetGate.openConnection`.
10. **Походження**: Власна реалізація MZGram.
11. **Ризики**: DeepL отримує текст повідомлення.

---

### 3.3. Mozhi Translation API
1. **Функція**: Переклад через децентралізований вільний проксі-рушій Mozhi. Вмикається: *Налаштування > MZGram > Загальні > Постачальник: Mozhi*. Типово вимкнено.
2. **Сервер**: `https://mozhi.themarkup.org/api/translate` або власний URL користувача, HTTPS (443).
3. **Коли**: При запиті перекладу.
4. **Що відправляється**: POST-запит з параметрами `engine`, `text`, `from`, `to`.
5. **Що приходить**: JSON із результатом перекладу.
6. **Що бачить сервер**: IP-адресу, текст для перекладу. Без авторизації.
7. **Ключі й акаунти**: Не потрібні.
8. **Вимкнення**: Перемикання постачальника на Telegram / Google.
9. **Код**: `MZGramTranslator.translateMozhi`, через `MZGramNetGate.openConnection`.
10. **Походження**: Власна реалізація MZGram.
11. **Ризики**: Інстанс Mozhi бачить текст перекладу.

---

### 3.4. LLM API (OpenAI, Anthropic Claude, Google Gemini, DeepSeek)
1. **Функція**: Інтелектуальний переклад та обробка повідомлень за допомогою мовних моделей. Вмикається: *Налаштування > MZGram > ШІ / Переклад*. Типово вимкнено.
2. **Сервер**:
   - OpenAI: `https://api.openai.com/v1/chat/completions`
   - Anthropic: `https://api.anthropic.com/v1/messages`
   - Gemini: `https://generativelanguage.googleapis.com/v1beta/models/...`
   - DeepSeek: `https://api.deepseek.com/chat/completions`
3. **Коли**: Лише за явним викликом ШІ-перекладу чи ШІ-підсумку.
4. **Що відправляється**: API-ключ користувача, системний промпт, виділений текст повідомлення.
5. **Що приходить**: Відповідь моделі з перекладом чи згенерованим текстом.
6. **Що бачить сервер**: IP-адресу, акаунт власника ключа, текст промпту.
7. **Ключі й акаунти**: Власні API-ключі користувача, збережені у налаштуваннях пристрою.
8. **Вимкнення**: Очищення ключів або вимкнення функції ШІ-перекладу.
9. **Код**: `MZGramAiService.*`, `HttpURLConnection` через `MZGramNetGate.openConnection`.
10. **Походження**: Власна реалізація MZGram.
11. **Ризики**: Провайдер ШІ обробляє переданий фрагмент тексту.

---

### 3.5. Веб-інтерфейси «Запитати ШІ» (WebView)
1. **Функція**: Відкриття діалогу з ШІ (ChatGPT, Claude, Gemini, DeepSeek, Grok) в ізольованому WebView із додаванням тексту або вкладень. Вмикається: меню повідомлення > «Запитати ШІ».
2. **Сервер**: `chatgpt.com`, `claude.ai`, `gemini.google.com`, `chat.deepseek.com`, `grok.com`.
3. **Коли**: Лише при натисканні пункту меню та підтвердженні переходу.
4. **Що відправляється**: Текст і файли передаються у поле вводу сторінки скриптом клієнта; на сервер вони йдуть тільки після натискання користувачем кнопки «Відправити» на сайті.
5. **Що приходить**: Веб-сторінка сервісу.
6. **Що бачить сервер**: Браузерний сеанс користувача з його власним входом на сайті.
7. **Ключі й акаунти**: Користувацький вхід у веб-версії відповідного сервісу.
8. **Вимкнення**: Не натискати пункт «Запитати ШІ» у меню повідомлення.
9. **Код**: `MZGramAiRules`, `PhotoViewerWebView`.
10. **Походження**: Власна реалізація MZGram.
11. **Ризики**: Сайт сервісу фіксує дії в межах свого звичайного веб-інтерфейсу.

### 3.6. DNS-over-HTTPS (DoH Резолвер)
1. **Функція**: Захищений резолвінг імен доменів через шифрований канал HTTPS для обходу цензури та блокувань DNS. Вмикається: *Налаштування > MZGram > Загальні > Мережа та завантаження > DNS-резолвер*. Типово вимкнено (режим Telegram за замовчуванням).
2. **Сервер**:
   - Cloudflare: `https://cloudflare-dns.com/dns-query`
   - Google: `https://dns.google/resolve`
   - AdGuard: `https://dns.adguard-dns.com/resolve`
   - Custom: Введений користувачем URL
3. **Коли**: Перед кожним встановленням TCP/TLS-з'єднання з серверами Telegram або зовнішніми API.
4. **Що відправляється**: Запит імені хоста (наприклад, `venus.web.telegram.org`), тип запису `A` або `AAAA`. Жодних даних користувача.
5. **Що приходить**: IP-адреси цільового сервера.
6. **Що бачить сервер DoH**: IP-адресу клієнта та доменне ім'я, яке запитується.
7. **Ключі й акаунти**: Не потрібні.
8. **Вимкнення**: *Загальні > Мережа та завантаження > DNS-резолвер: За замовчуванням (Telegram)*.
9. **Код**: `MZGramDoH.resolve`, `ConnectionsManager.ResolveHostByNameTask`, через `MZGramNetGate.openConnection`.
10. **Походження**: Exteraless (`app/exteraless/dns/*`) + MZGram адаптація.
11. **Ризики**: DoH-провайдер бачить домени, до яких звертається пристрій (але не бачить змісту трафіку).

### 3.7. Статичні прев'ю мап (OpenStreetMap / OpenFreeMap, Yandex, Google Maps)
1. **Функція**: Завантаження статичного зображення карти для повідомлень із геопозицією. Вмикається: *Налаштування > MZGram > Загальні > Мапи > Прев'ю геопозиції*.
   - Варіанти: Telegram (Google Maps), Yandex, OpenFreeMap (OSM), Ніхто (Nobody — вимикає завантаження повністю).
2. **Сервер**:
   - OpenStreetMap: `https://staticmap.openstreetmap.de/staticmap.php`
   - Yandex: `https://static-maps.yandex.ru/1.x/`
   - Google Maps: `https://maps.googleapis.com/maps/api/staticmap`
3. **Коли**: При відкритті чату, що містить повідомлення з локацією.
4. **Що відправляється**: Координати точки (широта, довгота), рівень наближення, розмір картинки.
5. **Що приходить**: PNG/JPEG зображення ділянки мапи. Кешується у стандартному дисковому кеші Telegram.
6. **Що бачить сервер**: IP-адресу клієнта та географічні координати з повідомлення.
7. **Ключі й акаунти**: Google API ключ (стандартний клієнтський Telegram), Yandex / OSM без ключів.
8. **Вимкнення**: Обрати варіант «Ніхто» (Nobody) у *Прев'ю геопозиції*. У цьому разі повертається `null` і жоден мережевий запит не виконується.
9. **Код**: `AndroidUtilities.formapMapUrl`, `MZGramNetGate.openConnection`.
10. **Походження**: Ported from exteraless (GPL-3.0) + власні розширення MZGram.
11. **Ризики**: Сервер мап дізнається координати, надіслані у чаті. Для повної приватності слід обрати «Ніхто».

---

### 3.8. Завантаження офлайн-моделей мови Vosk
1. **Функція**: Завантаження локальних мовних моделей для розпізнавання мови без передачі аудіо на сторонні сервери. Вмикається: *Налаштування > MZGram > Розпізнавання мови*.
2. **Сервер**: `https://alphacephei.com/vosk/models/...`, HTTPS (443).
3. **Коли**: Тільки при ручному натисканні кнопки завантаження конкретної моделі.
4. **Що відправляється**: Стандартний GET-запит файлу моделі.
5. **Що приходить**: ZIP-архів моделі Vosk, що зберігається локально у пам'яті програми.
6. **Що бачить сервер**: IP-адресу клієнта.
7. **Ключі й акаунти**: Не потрібні.
8. **Вимкнення**: Не завантажувати офлайн-моделі; розпізнавання виконується системним рушієм Android або не виконується.
9. **Код**: `MZGramSpeechRecognizer.downloadModel`, через `MZGramNetGate.openConnection`.
10. **Походження**: Власна реалізація MZGram.
11. **Ризики**: Мінімальні, публічне завантаження статичних файлів.

### 3.9. Синхронізовані тексти пісень (LRCLIB)
1. **Функція**: Показ синхронізованих рядків тексту пісні у музичному плеєрі Material 3. Вмикається: автоматично при програванні аудіофайлу за відсутності вбудованих тегів.
2. **Сервер**: `https://lrclib.net/api/get`, HTTPS (443).
3. **Коли**: При відкритті плеєра для музичного треку.
4. **Що відправляється**: Назва треку (`track_name`), виконавець (`artist_name`), тривалість (`duration`).
5. **Що приходить**: Текст пісні у форматі LRC з часовими мітками.
6. **Що бачить сервер**: IP-адресу, назву аудіотреку.
7. **Ключі й акаунти**: Не потрібні.
8. **Вимкнення**: Вимкнення відображення онлайн-текстів у налаштуваннях плеєра.
9. **Код**: `MZGramOnlineLyrics.fetchLyrics`, через `MZGramNetGate.openConnection`.
10. **Походження**: Власна реалізація MZGram.
11. **Ризики**: Сервер LRCLIB бачить назви пісень, які слухає користувач.

### 3.10. Курси криптовалют та дорогоцінних металів (Pill Stack)
1. **Функція**: Відображення актуальних біржових курсів у пошуковому рядку списку чатів. Вмикається: *Налаштування > MZGram > Оформлення > Pill Stack > Курси валют*. Типово вимкнено.
2. **Сервер**: `https://api.coinbase.com/v2/prices/...`, `https://api.gold-api.com/price/...`, HTTPS (443).
3. **Коли**: Періодично раз на 15 хвилин при відкритому списку чатів.
4. **Що відправляється**: Запит ціни торгової пари (BTC-USD, ETH-USD, XAU, XAG).
5. **Що приходить**: Числове значення вартості.
6. **Що бачить сервер**: IP-адресу клієнта.
7. **Ключі й акаунти**: Не потрібні.
8. **Вимкнення**: *Налаштування > MZGram > Оформлення > Pill Stack* (обрати інший піл або вимкнути).
9. **Код**: `MZGramRatesPill.updateRates`, через `MZGramNetGate.openConnection`.
10. **Походження**: Власна реалізація MZGram.
11. **Ризики**: Мінімальні, стандартні відкриті фінансові API.

### 3.11. Перевірка та встановлення оновлень MZGram (GitHub)
1. **Функція**: Сповіщення про вихід нових релізів MZGram та безпечне завантаження оновлень із перевіркою цифрових контрольних сум. Вмикається: *Налаштування > MZGram > Інше > Оновлення*. Типово увімкнено.
2. **Сервер**: `https://api.github.com/repos/dmytrokurochkin/MZGram-Android/releases/latest`, `https://github.com/.../releases/download/...`, HTTPS (443).
3. **Коли**: При старті застосунку раз на кілька годин або при ручному натисканні «Перевірити оновлення».
4. **Що відправляється**: Заголовок `User-Agent: MZGram-Android/<version>`.
5. **Що приходить**: Метадані релізу (номер версії, опис змін, URL APK-файлів та `SHA256SUMS`).
6. **Що бачить сервер GitHub**: IP-адресу клієнта, поточну версію застосунку.
7. **Ключі й акаунти**: Не потрібні.
8. **Вимкнення**: *Налаштування > MZGram > Інше > Сповіщати про оновлення* (Вимк.).
9. **Код**: `MZGramUpdateChecker`, `MZGramUpdateInstaller`, через `MZGramNetGate.openConnection`.
10. **Походження**: Власна реалізація MZGram.
11. **Ризики**: GitHub реєструє звернення за версіями релізів.

### 3.12. Шлюз сповіщень UnifiedPush
1. **Функція**: Доставка push-сповіщень через незалежні сервери без обов'язкового використання Google Play Services. Вмикається: *Налаштування > MZGram > Загальні > Сповіщення > Служба push: UnifiedPush*.
2. **Сервер**: `https://p2p.belloworld.it` (стандартний шлюз) або інший шлюз, вказаний користувачем.
3. **Коли**: При реєстрації push-каналу або отриманні нового повідомлення.
4. **Що відправляється**: Анонімний токен пристрою та зашифрований корисний вантаж повідомлення.
5. **Що приходить**: Підтвердження доставки push-пакета.
6. **Що бачить сервер шлюзу**: IP-адресу дистриб'ютора / пристрою, зашифровані пакети. Шлюз не має ключів розшифрування вмісту.
7. **Ключі й акаунти**: Ключі шифрування генеруються виключно на пристрої та не передаються третім сторонам.
8. **Вимкнення**: Вибір іншої служби доставки або вимкнення сповіщень.
9. **Код**: `MZGramUnifiedPushRules`, `MZGramReliableService`.
10. **Походження**: Власна реалізація MZGram.
11. **Ризики**: Шлюз бачить факт надходження сповіщення та час активності, але не вміст.

## 4. Контроль та журналювання через `MZGramNetGate`

Усі вихідні мережеві виклики проходять контроль через єдиний шлюз:
```java
// Перевірка дозволу та логування перед з'єднанням
HttpURLConnection conn = MZGramNetGate.openConnection(new URL(endpoint), MZGramNetGate.FEATURE_TRANSLATION);
```

У системному журналі `logcat` кожна спроба з'єднання фіксується одним рядком:
```text
MZGramNet: [ALLOWED] feature=translation host=translate.googleapis.com
MZGramNet: [BLOCKED] feature=doh host=cloudflare-dns.com (feature disabled in settings)
```

Жодні паролі, ключі авторизації, персональні токени чи фрагменти листування в журнал **ніколи не записуються**.
